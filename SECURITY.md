# Security

ACP Red Star keeps the local archive in a SQLCipher database under `~/.acp`. The password, the recovery phrase, and node secrets are not written to logs or command-line arguments.

Report a vulnerability through the repository's GitHub security advisories: https://github.com/m3talsmith/acp-rs-scraper/security

The repository URL is unchanged. A GitHub rename of the repository, if it happens later, redirects that address.
