1//! ACP Red Star (<https://acp.us/rs>) scraper library.
2//!
3//! Logs in to the Red Star forum (a Phoenix LiveView app), scrapes members'
4//! posts, replies, mentions and profiles into SQLite, downloads attachments,
5//! and exports/imports JSON or HTML. The binary (`src/main.rs`) is a thin
6//! wrapper around [`app::run`].
7//!
8//! Modules by domain:
9//! - [`cli`]: command-line arguments, nick parsing, prompts, man/completions.
10//! - [`config`]: every constant (paths, site URLs, LiveView events, selectors)
11//!   plus the `ACP_BASE_URL` override used by the mocked end-to-end tests.
12//! - [`logging`]: `-q`/`-v`/`--debug` levels and the `info!`/`verbose!`/`err!` macros.
13//! - [`http`]: the Firefox-like HTTP client.
14//! - [`auth`]: email + one-time-code login, saved preferences.
15//! - [`liveview`]: LiveView websocket client and diff renderer.
16//! - [`scrape`]: profile/site feeds, threads, "Posts and replies" filter, mentions.
17//! - [`media`]: attachment discovery and download.
18//! - [`storage`]: SQLite schema and queries.
19//! - [`export`]: JSON / HTML rendering and `.tar.gz` archives; [`import`] reads them back.
20//! - [`maintenance`]: `--remove-nick` and `--clear-all`.
21//! - [`tui`]: the terminal UI (the default with no flags): browse nicks and posts,
22//!   drive scrape/search/export/import/maintenance from a menu bar.
23//! - [`app`]: wires the above into the command-line program.
