Module bookmarks 

Source
Expand description

Bookmarks: local first (they work offline), synced with the site’s own bookmarks by --sync-bookmarks (pull the site’s list, store its posts, push local additions/removals). Stored in the bookmarks table of the database so they follow --clear-all and can be joined with posts.
