pub fn output_files(

    formats: &[Format],

Expand description

Where each format goes for a plain (uncompressed) --output path. One format: the path as given (a directory gets <name>.<ext>). Several: a directory gets <dir>/<name>.<ext> each; a file path keeps its stem and gets one <stem>.<ext> per format (out/x.json -> out/x.json, out/x.html).
