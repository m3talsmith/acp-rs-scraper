export
Write an export (JSON or HTML) to stdout, --output, or a .tar.gz archive with an attachments/ folder, as selected in args.
export_with
export plus an optional research section; research files must be in atts (see item_attachments) so bundles copy them.
output_files
Where each format goes for a plain (uncompressed) --output path. One format: the path as given (a directory gets <name>.<ext>). Several: a directory gets <dir>/<name>.<ext> each; a file path keeps its stem and gets one <stem>.<ext> per format (out/x.json -> out/x.json, out/x.html).
remove_export_dir
Delete the uncompressed export folder dir after archive was written. Refuses when the archive is missing/empty or would live inside dir.
render
