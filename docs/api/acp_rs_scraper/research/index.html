Module research 

Source
Expand description

Research projects: named collections of posts, replies, search results, local files and web pages, each with an optional note, exported together (JSON + HTML, or a bundle with the files and page snapshots).

Stored in the research_projects / research_items tables of the main database. Local files are copied to ~/.acp/research/<project>/files/ (unless --no-copy); web pages are fetched once and kept as an HTML snapshot in ~/.acp/research/<project>/web/ plus their readable text.
