Module logging 

Source
Expand description

Logging levels (-q, default, -v, --debug) and the info!, verbose!, err! macros.

With --enable-logging (or --debug, --log, --error-log) every message the macros emit is also appended, timestamped, to a log file: progress, verbose detail and debug wire frames go to the success log, errors and warnings to the error log. Stderr still follows -q/-v. Debug wire frames are passed through redact_secrets so CSRF tokens and signed sessions never land in stderr or the success log.
