Profile “Posts and replies” feed filter.

Verified live on the logged-in site: the profile page has a Filter dialog (<dialog id="js-configureFeed">) with <form phx-submit="configure-feed"> and radios name="replies" (0 = Posts, the default; 1 = Posts and replies). Submitting patches the URL to /rs/@{nick}?replies=1, and the feed then also lists the nick’s replies (“Replying to …”). The scraper loads that URL directly and pages it with page-next; if the URL has no feed, it falls back to pushing the configure-feed form on the profile LiveView.
