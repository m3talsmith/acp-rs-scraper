Expand description

Fail when a profile URL (/rs/@nick) did not land on that profile. ACP answers an unknown nick with a 302 to /rs (Trending) and a flash “No profile exists with the username @nick”; reqwest follows redirects, so without this check the Trending feed would be scraped as the profile.
