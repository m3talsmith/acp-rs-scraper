Functions§

check_profile_landing
Fail when a profile URL (/rs/@nick) did not land on that profile. ACP answers an unknown nick with a 302 to /rs (Trending) and a flash “No profile exists with the username @nick”; reqwest follows redirects, so without this check the Trending feed would be scraped as the profile.
fetch_feed
Fetch a feed page (profile, site or filter URL), then page it to the end with page-next, honouring limit and incremental early-stop against known.
merge_feed_items
Append extra feed items whose id isn’t already in items. Returns how many were added.
page_all_known
True when every id in page is already known (and the page is non-empty).
page_rest
Page a feed that is open on lv to its end with page-next {cursor}, appending new (id-deduped) posts to items. Returns (stopped_incremental, extra_pages). Shared by profile, site and “Posts and replies” feeds so incremental/limit rules are identical.
profile_nick_of
Nick from a /rs/@{nick} URL path, if it is a profile URL.
