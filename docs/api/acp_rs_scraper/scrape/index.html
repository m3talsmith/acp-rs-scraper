Functions§

body_text
Plain text of a post body in any of the shapes the site sends: a ProseMirror doc (object or JSON string), a plain-text / Markdown / HTML string, or an object with html / text / markdown. Falls back to the body_text_summary, body_text, body_html, text and string content fields.
html_to_text
Strip HTML tags (block tags become newlines) and decode common entities.
prosemirror_text
Flatten a ProseMirror doc ({type, text?, content:[...]}) to plain text.
reply_ref
The post a reply answers directly: the first postRef node (attrs.postId) in its ProseMirror body, wrapped or not, skipping own. The site keeps threads flat (thread_id only); nesting under a comment is this reference. None when the body has no reference.
s
String field k of a JSON object, or "".
said_by_nick
Whether a feed item was written by nick (--said-by). Items with no author data are kept: profile feeds only list the nick’s own items.
scrape
Scrape a nick: the Posts feed and the “Posts and replies” filter (merged by id), then replies in every thread the nick started that changed since the last run. Returns the posts, the profile HTML and counts.
to_post
Convert site post JSON to a Post with the given parent ("" for roots), flattening the body to text.
