Shared constants, grouped by domain, and the site base URL.

The site URL defaults to https://acp.us and can be overridden with the ACP_BASE_URL environment variable (e.g. http://127.0.0.1:4000), which is how the mocked end-to-end tests point the scraper at a local fake server. Websocket URLs follow the scheme (http → ws, https → wss).
