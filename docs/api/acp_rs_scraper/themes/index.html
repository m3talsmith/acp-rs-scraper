Module themes 

Source
Expand description

Theme files: every theme, the default included, is ~/.acp/themes/<name>.toml ([format] describes the file). Nothing is built into the binary: the packages ship themes/*.toml in /usr/share/acp-rs-scraper/themes/, and the first run copies them into an empty ~/.acp/themes. A missing or broken theme falls back to the terminal’s own colours (Color::Reset) with a notice; broken files are never overwritten.
