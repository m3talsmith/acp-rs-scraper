acp_rs_scraper::themes

Module download 

Source
Expand description

Downloading theme files from the repo’s themes/ folder at this version’s tag (THEME_DOWNLOAD_BASE, or THEME_URL_ENV in tests). The first run with an empty ~/.acp/themes fetches default.toml in the background; --theme-init and Theme: init fetch on request. Each download is capped at THEME_MAX_BYTES and THEME_DOWNLOAD_TIMEOUT, must parse as a theme, sends no cookies, and is written atomically (mode 0600) without replacing an existing file.
