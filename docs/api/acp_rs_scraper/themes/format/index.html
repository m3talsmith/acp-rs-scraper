acp_rs_scraper::themes

Module format 

Source
Expand description

The theme file format, v1 (TOML):

version = 1
name = "default"
description = "ACP red on your terminal's colours"

[dark.palette]            # colours; any extra name can be referenced as "@name"
accent = "#dc2626"
muted = "#9ca3af"

[dark.styles.link]        # optional per-element overrides
fg = "@accent"
underline = true

[light.palette]           # optional; missing keys fall back to [dark]

A colour is 0–255 (the 256-colour palette), #rrggbb / #rgb, one of the 16 ANSI names (black … white, bright_black … bright_white), reset (the terminal’s own colour), or @name for a palette entry. Borders and padding are fixed in code; a style sets colours and attributes.
