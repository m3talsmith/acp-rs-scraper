Module empty_anim 

Source
Expand description

The animation in the empty Body: text frames played on a loop.

Frames come from ~/.acp/animations/empty-body.acpanim(.gz) (made with tools/acp-anim), [ui] empty_animation_path, or the built-in clip (assets/empty-body.acpanim.gz, see assets/empty-body.NOTICE.md); if that can’t be read, or [ui] empty_animation = "star", a procedural red star is drawn instead. [ui] empty_animation = false or ACP_EMPTY_ANIMATION=off turns it off.

Format (gzip or plain UTF-8): ACPANIM 1, fps N, size COLS ROWS, then each frame as a %% line followed by up to ROWS lines.
