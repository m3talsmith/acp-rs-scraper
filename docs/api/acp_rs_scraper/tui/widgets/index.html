Post detail content, at parity with the HTML export: Post/Reply badge, @nick · posted_at · post_id, “Replying to … · thread …”, title, body with its paragraphs, attachments (path + open hint), and every cross-link.

Menu bar (commands from the CLI flags, Start Scanning pinned right) and its dropdown of options with checkbox / dropdown / text field / button inputs.

Modal rendering: dims the layout, then draws the modal with a small margin.

Left nick bar: @nick and post count; multi-select.
text
Single-line text field state (cursor editing), shared by menu options and modals.
