Module markdown 

Source
Expand description

Post bodies as Markdown → styled, word-wrapped ratatui lines.

CommonMark plus the GitHub extensions (tables, task lists, strikethrough, footnotes) parsed by pulldown-cmark into a small block tree, then laid out to a width: headings H1–H6 (a ━ / ─ rule under H1 / H2), bold, italic, strikethrough, inline code, boxed code blocks, block quotes with a ┃ gutter, bullet / numbered / task lists (nested, tight or loose) with hanging indents, box-drawn tables with aligned, wrapping columns, rules, links and autolinks (bare https:// URLs too) with their URL shown, images as links, and footnotes listed at the end. Every style comes from the Theme (the markdown elements h1…footnote).

Single line breaks are kept: post bodies are stored as plain text whose newlines matter. normalize first repairs what the site’s plain text does to Markdown (typed • bullets, a lone indented line used to centre text), and simple inline HTML (<b>, <br>, <a href>, …) is honoured.
