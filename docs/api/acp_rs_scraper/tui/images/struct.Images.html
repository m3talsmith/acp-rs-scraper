pub fn new( protocol: Protocol, cell: (u16, u16), background: bool, badge: [u8; 3], ) -> Self

Images drawn with protocol; background decodes on a worker thread (else inline, for tests). The logo is laid on a badge colour so the red star stays visible on the red header.

Source

pub fn detect(badge: [u8; 3]) -> Option<Self>

Detect the terminal’s graphics support (call in raw mode, before the input thread reads stdin). ACP_IMAGES=off disables pictures; ACP_IMAGE_PROTOCOL=halfblocks|sixel|kitty|iterm2 forces a protocol.

Source

pub fn get(&mut self, path: &Path) -> &mut ImgState

The state of path, starting its decode on first use.

Source

pub fn poll(&mut self) -> bool

Take finished decodes from the worker; true when something changed.

Source

pub fn draw_logo(&mut self, buf: &mut Buffer, area: Rect) -> bool

Draw the logo into area. With half blocks it is drawn in two colours with sextant cells instead (2×3 dots per cell), which keeps the star’s points at header size.

Source

pub fn draw_file( &mut self, buf: &mut Buffer, area: Rect, path: &Path, graphics: bool, ) -> Result<(), String>

Draw the picture at path into area (left-aligned, aspect kept). graphics = false forces half blocks (e.g. under a modal). Err = what to show instead.
