Module images 

Source
Expand description

Pictures in the terminal: the header logo and post images.

The graphics protocol is found once at start by querying the terminal (kitty graphics reply, sixel in the DA1 attributes, cell size via CSI 16 t), with iTerm2 inline images picked from the environment (iTerm2, WezTerm). Anything that doesn’t answer — the Linux console, tmux, many SSH, waypipe and Windows-terminal setups — gets Unicode half blocks, which are drawn straight into the ratatui buffer and work everywhere.

Graphics protocols are drawn after ratatui’s frame, like the OSC 8 links: widgets reserve blank cells and record a Placement; Images::flush emits the escapes only when the placements change (kitty deletes and re-places; sixel / iTerm2 ask for a full repaint first so no fragments stay). Images decode on a worker thread; AVIF/HEIC (the site’s format) are converted once to a cached PNG with avifdec, magick or ffmpeg.

This is hand-rolled rather than ratatui-image because that crate’s sixel encoder pulls in a quantiser that needs Rust 1.90, above our MSRV (1.88).
