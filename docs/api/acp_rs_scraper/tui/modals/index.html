Module modals

Modals: floating over the layout (small margin, dimmed background), each closing with ModalResult::ClosedCancelled or ModalResult::ClosedSubmitted.

Modules§

confirm
Confirm modal: destructive Maintain actions, and quitting while a job runs.
help
Help modal: the real --help text (generated from clap, so it cannot drift) plus the TUI key bindings.
login
Login modal: email, then the emailed one-time code (or the login link). The modal only collects input; the app runs the login and reports back.
message
Error / status modal with an OK button.
palette
Ctrl+Space command palette: type to filter every command, Enter runs it.
research
Research modal: pick a project (or create one), then add the chosen thing to it (r on a post, the Research menu’s Add buttons). In browse mode (Research › Projects…) it only picks or creates a project to show.
search
Shift-S search modal: keyword, nicks, post id, date range, posts/replies.
