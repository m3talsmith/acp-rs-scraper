The menu bar’s command catalog and the menu → command-line bridge.

Every menu command maps to CLI flags (see SPECS “Menu bar ↔ CLI flag map”). Actions that change data (scrape, export, import, maintenance) are turned into the exact argv the headless CLI takes, validated by clap (parse_with_mode), and run as a child process, so the TUI and the CLI share one code path.
