Expand description

A declarative, chainable style definition, modeled on Lip Gloss’s lipgloss.Style.

A Style is a plain value: every builder method takes self and returns a new style, so cloning is copying and nothing is ever mutated behind your back. Every rule is optional: an unset rule is different from a rule set to its default, which is what makes Style::inherit work.

A style can be used in three ways:

  1. Inline: convert it to a ratatui Style (it implements Into<ratatui::style::Style>), so it works anywhere ratatui accepts a style: Span::styled("hi", &style), Paragraph::new(..).style(&style), or Style::apply.
  2. Rendered: Style::render lays out content (wrapping, padding, alignment, sizing, borders, margins) and returns a ratatui Text that you can render as a widget or compose further with join_horizontal, join_vertical and place.
  3. Around a widget: Style::wrap (or WidgetStyleExt::styled) wraps any ratatui widget, drawing margin, border and padding around it.
use ratatui_lipgloss::{Border, Style};

let style = Style::new()
    .bold(true)
    .foreground("#FAFAFA")
    .background("#7D56F4")
    .padding_top(2)
    .padding_left(4)
    .width(22);

let text = style.render("Hello, kitty");
assert_eq!(text.lines.len(), 3);
assert_eq!(text.lines[2].width(), 22);

let boxed = Style::new().border(Border::rounded()).padding((0, 1));
assert_eq!(
    ratatui_lipgloss::to_plain_string(&boxed.render("hi")),
    "╭────╮\n│ hi │\n╰────╯"
);

impl Style

pub fn render<'a>(&self, content: impl Into<Text<'a>>) -> Text<'static>

Renders content with every rule of this style applied, returning an owned ratatui [Text].

content can be anything that converts into Text: &str, String, Span, Line or Text. Styles already present on the content are preserved and take precedence over this style’s inline rules.

The result is a regular ratatui widget (frame.render_widget(text, area)), can be put in a Paragraph, measured with width / height, or combined with join_horizontal, join_vertical and place.

Layout order: tabs → wrap (to width - horizontal padding) → horizontal alignment (to width) → vertical alignment (to height) → padding → border → margin → max_width / max_height truncation.

pub fn render_with<'a>( &self, content: impl Into<Text<'a>>, dark_background: bool, ) -> Text<'static>

Like Style::render but with an explicit light/dark background flag for adaptive colors.

where I: IntoIterator<Item = C>, C: Into<TerminalColor>,

Sets a gradient for the border foreground, blended around the whole perimeter clockwise from the top-left corner (Lip Gloss v2’s BorderForegroundBlend). It overrides the other border foreground colors.

With no colors this does nothing; with a single color it is the same as Style::border_foreground. When all sides are drawn you will usually want the first and last color to match so the gradient wraps around smoothly.

use ratatui_lipgloss::{Border, Style};

let s = Style::new()

    .border_foreground_blend(["#00FA68", "#9900FF", "#ED5353", "#00FA68"]);
let text = s.render("gradient");
let top = &text.lines[0].spans;
assert_ne!(top.first().unwrap().style.fg, top.last().unwrap().style.fg);

Copies every rule that is set on other but unset on self.

Like Lip Gloss, margins, padding and the underlying string are not inherited. If other has a background and self has neither a background nor a margin background, the margin background is inherited from it.

use ratatui::style::Color;
use ratatui_lipgloss::{Style, TerminalColor};

let a = Style::new().foreground(229u8).background(63u8);
let b = Style::new().foreground(201u8).inherit(&a);
assert_eq!(b.get_foreground(), Some(TerminalColor::Color(Color::Indexed(201))));
assert_eq!(b.get_background(), Some(TerminalColor::Color(Color::Indexed(63))));

impl Style

pub fn layout(&self, area: Rect) -> BoxLayout

Computes the box model of this style inside area.

  • max_width / max_height clamp the area.
  • Margins are taken from the outside.
  • If width / height are set, the box (padding + content, plus borders) gets that size and is placed inside the remaining area using the horizontal / vertical alignment; otherwise it fills it.
  • Borders and padding are taken from the box; the rest is content.
use ratatui::layout::Rect;
use ratatui_lipgloss::{Border, Style};

let s = Style::new().margin(1).border(Border::normal()).padding((0, 1));
let l = s.layout(Rect::new(0, 0, 20, 10));
assert_eq!(l.content, Rect::new(3, 2, 14, 6));

pub fn inner(&self, area: Rect) -> Rect

The area available to content inside area (see Style::layout).

pub fn wrap<W>(&self, widget: W) -> StyledWidget<W>

Wraps a widget so that it is rendered inside this style’s margin, border and padding, with this style’s inline rules applied to the whole box.

Works with both [Widget]s and [StatefulWidget]s.

pub fn render_frame(&self, area: Rect, buf: &mut Buffer) -> Rect

Draws the frame (margins, padding background, border) of this style into buf and returns the content area. This is what [StyledWidget] does before rendering its inner widget; use it directly for custom rendering.
