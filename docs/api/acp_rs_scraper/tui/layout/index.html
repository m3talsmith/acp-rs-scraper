Screen geometry (pure, so it is unit-tested): the base layout, the post list ↔ detail split (the “slide up”), and the nested detail stack (the “push the previous detail up”).

detail_split
Lay out the list around the detail of post cursor (of n), p = slide progress. Fully open, the list keeps DETAIL_RESIDUAL_ROWS rows: one above (when there is a previous post) and the rest below; while sliding, the detail grows from the selected row and the rows below are pushed down and out.
ellipsize

lerp 🔒
modal_rect
Centered rect of at most w×h inside r with a 1–2 cell margin.
stack_layout
Stack layout for n frames; push = progress of the latest push (1.0 = settled). Frame 0 (the post opened from the list) fills inner alone; with more frames it collapses to a DETAIL_HEADER_ROWS header and the rest nest in a box below it, where every frame but the top one is a header too. A push animates the previous top frame from its full height down to a header.
wrap
Word-wrap text to width columns, keeping its newlines (blank lines stay).
