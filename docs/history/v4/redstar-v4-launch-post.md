# ACP Red Star 4.0: The library got wider. The reading stayed yours.

Comrades,

Today, ACP Red Star 4.0 ships. The client you already know still holds our forum, encrypted, on your machine. What is new is research. The library reaches further, and a model on your own computer helps you get through it.

This post is written for the day 4.0 is done. It is not published before that day.

## One archive. Many sources. A name on every line.

A post in 4.0 tells you where it came from. A Red Star post. A transcript turn. Each row has a source, an identifier, and a URL. A transcript segment has a start and an end. Your older rows came in as Red Star. Nothing was copied into a second database. The same encrypted file opened, grew a few columns, and kept your password.

Search still finds the words you type. You can also see, on the item itself, which stream or which thread it belongs to.

## The streams, checked

@hazaldin, the corpus is your streams. All of them. All of the data from all of the streams.

We did not pour raw captions into a model and call it a day. Transcripts were reviewed and corrected. Every correction is still there: what the text used to say, who changed it, and whether that earlier text came from a machine or from a person. The latest wording is what you read. The history is what you can audit.

Speakers are labeled. In a debate, Haz is one turn and the debater is the next. A guest is named, not blended into the host. Each turn points at the stream and the timestamp, so you can go listen.

## A local assistant, on your machine

Ask the archive a question. The assistant runs inside ACP Red Star, over the material you already store. It can drive the actions you already had: search, filter, export. The chat sits in the terminal with the rest of the app. It reads the archive on your machine.

## What 4.0 left alone

Comrade-to-comrade sync, relays, and the network node stayed in the 3.x line, where we already planned them. 4.0 did not pick that work up and did not push it aside. Live publish is still the careful path the client already had. This version widens research. It does not reopen the question of who holds the network.

## Why this matters

The future belongs to the working class, and the working class needs a memory it can search. Education, debate, and the long public conversations around them should be readable together, with the source still attached, on a machine you control.

ACP Red Star 4.0 is that reading room. Local. Encrypted. Open source. Built for the people who already call Red Star home.

The plan we built it from is [architecture/PLAN-4.0.md](../../../architecture/PLAN-4.0.md).
